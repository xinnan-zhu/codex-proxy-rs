# v3.23.1

## 修复与改进

- 使用统计的总费用卡片显示「每 $1 可跑多少 M Token」，仅用计费完整的 USD 请求计算，忽略计费不完整的请求并移除对应提示；无可计算费用时显示占位值
- OpenAI 流式请求在语义输出或终态事件出现前暂存结构性前导事件，避免过早交付；输出前遇到可恢复的 WebSocket 故障时支持同账号重试
- WebSocket 收到关闭帧或读错误后立即失效，拒绝向已关闭连接发送，跳过已取消的排队消息，并保留关闭原因及静默时长供排查
- 优化请求观测查询投影，减少无关 JSON 字段处理，改善索引与并行查询计划
- 统一管理端表单、弹窗、加载状态及通知组件，改善健康时间线弹层跟随鼠标的稳定性

## 升级事项

- 启动时自动执行观测视图优化迁移（官方 `0027` 及 fork 的 `900009`），确保新安装与已有数据库采用相同投影，保留观测视图列顺序、类型及值语义，不改写历史请求；升级前建议备份数据库
- 输出前的 WebSocket 恢复使用 `stream_max_retries`（默认 `5`）；恢复为尽力重试，上游可能重复执行
- 前导事件缓冲不设固定等待或大小限制，请求取消、截止时间及传输超时仍然生效
