# v3.31.3

## 更新与改进

- 合并官方 v3.30.0 至 v3.31.3，管理端支持简体中文、繁体中文和英文，语言资源按需加载，切换时同步更新组件、图表与通知
- 改进账号、密钥、插件与系统设置页面的表单、导航和窄屏布局，统一 Codex 平台名称，记住表格排序，完善插件能力标签及敏感配置操作
- 优化用量查询、账号批量读取和性能图表数据，减少 WebSocket 转发中的复制；Client Key 额度结算移出请求关键路径，仍保持额度预占和结算约束
- 保留客户端轮次标识，隔离 Live 通话关联信息，修复流式 404 导致账号被误判失效、错误清理时 WebSocket 停滞，以及受管适配器会话亲和问题
- 插件支持按账号选择受管上游适配器，并通过出站中间件组合原生 Provider 请求，响应观测保持只读，统一移除 Provider 专属请求参数和冗余模型观测字段
- 保留本 fork 的账号客户端限制、周期费用与重置进度、xAI 额度刷新和推理强度、模型筛选、每 $1 可跑 M Token、估算速率标注及更新下载代理，并接入三种界面语言
- 全局模型选择继续同步筛选请求列表、总费用和洞察图表，同时保留上游新增的明细 Key 名称、账号名称和模型模糊搜索
- 更新 UI 组件与依赖，修复已知安全问题，完善诊断快照大小限制与备份工具兼容性

## 升级说明

- 插件 RPC 协议仍为 v5，`middleware` 能力升至 v6、`upstream_adapter` 升至 v5。使用这些能力的插件需按当前 SDK 适配并重新构建，不能只修改清单中的版本号
- 插件请求准备改用出站中间件，`service_tier`、请求轮次及路由等 Provider 专属字段不再由模型调用合同承载，详情以新版 SDK 为准
- 请求记录保留客户端请求模型和网关发送模型，不再保存或展示响应上报模型
