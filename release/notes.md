# v3.29.5

## 修复与改进

- 合并官方 v3.29.3 至 v3.29.5 更新，修复大历史数据量或缩短保留天数后，使用统计与请求健康时间线停止更新的问题
- 修复 OpenAI 套餐额度耗尽但仍有可用点数时无法调度的问题，改进额度重置后的后台复核与账号恢复
- 缓解 Codex OAuth 旧会话携带搜索历史但缺少工具声明时的一类上游 500 错误，覆盖普通请求与 Lite 压缩
- OpenAI 首字延迟从首个非空响应载荷开始计时，覆盖 HTTP SSE 与 WebSocket，首推理与首正文仍按实际内容计时
- 代理连接测试同步刷新出口地区，失败或出口时区冲突时不再显示旧地区；统一管理端失败反馈，简化并发明细弹窗
- PostgreSQL 与 Redis 密码支持 16–128 字节，修复字面量百分号序列导致的认证失败；更新前后端及工作流依赖
- 保留本 fork 的账号客户端限制、额度展示、xAI 额度刷新与推理强度记录、模型筛选、每 $1 可跑 M Token 统计，以及缺少上游计时时明确标注的估算速率

## 升级说明

- 首字延迟统计口径有变化，新旧版本数值不宜直接比较；HTTP SSE 空载荷与 `[DONE]` 不计入首字
- 搜索历史补偿禁用外网搜索；无工具请求补偿后禁止调用工具，已有工具请求保留原选择策略，新增声明可能允许模型使用缓存搜索
- 数据库与 Redis 的现有密码继续有效；配置和环境变量填写原始密码，不要预先 URL 编码，拒绝全空白及控制字符
