# v3.29.2

## 新增与改进

- 合入官方 v3.27.0 至 v3.29.2 及当前 main 更新，保留本 fork 的账号客户端限制、额度费用、模型筛选、每 $1 Token 效率、xAI 额度刷新与速率估算
- 请求记录统一展示成功、失败及未完成状态，支持最近 31 天日期范围选择，默认查看今天；改进详情、诊断导出与历史数据维护
- 账号支持自动使用即将到期的额度重置卡，默认关闭，可配置提前时间与剩余周额度上限；点击并发数量可查看占用请求详情
- 代理管理支持批量添加、测试与出口检测，并可限制同一代理的 OpenAI Responses WebSocket 连接数；系统设置可检测服务器直连出口位置
- 账号分组支持控制生图权限，隐私规则编辑与健康时间线展示进一步完善

## 修复与调整

- 修复 OpenAI 与 xAI 换号耗尽时丢失原始上游错误的问题，改进会话策略限制与备用 Provider 的错误处理
- 生图编辑接口支持 multipart 上传，独立 Search 遵守账号模型访问策略；改进 OpenAI 请求处理顺序与计时采集
- 修正仪表盘昨日趋势对比、前端异步状态及登录会话处理，更新 UI 与安全依赖
- 修复重复运行安装脚本时应用私有文件所有权被改写的问题

## 升级事项

- 升级前备份数据库。本 fork 保留已发布 `0031`、`0032` 的编号与字节，通过新增 `0033`、`0034` 接入上游代理、重置卡、表名及调度变更；不能将官方同号迁移直接覆盖到 fork 数据库
- 请求记录与统计保留期统一为 1～31 天，已有超过 31 天的配置收敛为 31 天；智能调度移除自动回切设置，已有其他系数保留
- 插件 RPC 协议升级为 v4，旧插件需使用匹配的 SDK 与 CLI 重新构建、打包
- 自定义调用方需适配统一请求状态；代理创建与测试 API 改为接收 1～100 项数组，并逐项读取处理结果
- xAI 本地选号终态错误状态码由 502 改为 503；存在可交付的原始上游错误时保留上游结果
- 源码构建工具链更新为 Node.js 26.12.0 与 Rust 1.99.1；发行包仍在 bookworm 上构建，保持 glibc 2.36 兼容
