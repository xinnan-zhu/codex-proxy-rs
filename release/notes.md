# v3.33.0

## 升级提醒

- 插件 RPC 协议由 v5 升级为 v7，宿主仅支持 v7；已安装插件需使用本版本 SDK 重新构建、打包并更新，仅修改清单版本号不能完成升级
- 如果已配置 `openai.account_routing_override` 且频繁遇到 `turn_rate_limit_exceeded`，建议将其改为 `null` 并重启服务；本版示例配置默认为 `null`，升级不会自动修改已有配置

## 插件调用与运行状态

- 支持按调用阶段声明处理时长，宿主与 SDK 共用预算；维护任务默认处理预算调整为 120 秒，并补充预算来源、实际耗时与结束原因诊断
- 插件等待宿主回调时可归还执行名额，恢复前重新取得名额；统一回调结果的消费、取消和回收，修复交叉调用可能因容量相互等待的问题
- 无关配置发布不再打断正在执行的维护任务，停用或替换实例时等待旧任务取消或退出，避免维护重叠
- 认证、账号授权和模型目录查询与模型执行准入分离，同一父调用内复用身份与权限快照；SDK 增加客户端认证、账号与模型授权检查、完整额度查询和按账号当前代理发送 HTTP 请求的能力
- 插件管理页显示实际运行状态，详情展示当前会话的在途、执行、排队、回调和活动流等负载；缺少诊断时显示未知

## OpenAI 请求与错误处理

- 支持可选的 `openai.residency` 与 `openai.account_routing_override` 字符串配置，填写值原样发送，省略或 `null` 时删除对应请求头且不补发；修改后重启生效
- WebSocket 连接池按账号路由头区分连接，避免复用携带不同握手头的连接
- 修复上游 WS 错误转换为 SSE `response.failed` 时丢失事件级 `Retry-After` 的问题，保留错误对象已有的有效等待值

## 模型选择与界面

- 已选但当前上游目录未返回的模型保留选中样式并显示警示，可查看完整模型 ID 与提示；目录加载中或请求失败时不误报模型缺失
- 模型选择浮层中的长名称自动换行，刷新按钮位置调整；同步简体中文、繁体中文和英文文案
- 同步上游依赖与前端格式规范，并保留本 fork 的费用效率、模型筛选、估算速率、账号额度和更新代理等定制能力
