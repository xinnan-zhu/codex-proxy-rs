# v3.9.1

## 新增功能

- 支持上游 API Key 账号，可配置服务地址与传输方式，使用模型列表、连接测试和本地用量统计；支持手动添加及兼容格式的批量导入。请求与响应复用 OAuth 的现有透传链路，Responses、Images、独立 Search、Lite 和原生压缩的实际支持情况由上游决定；
- 批量导入改为后台任务，提供逐项进度、结果和停止待处理任务的入口；关闭页面后任务继续执行。任务队列保存在内存中，重启服务前请等待导入结束，已成功导入的账号不受影响。
- 新增可选的账号容量冷却：容量类错误达到阈值后暂时停止调度，支持恢复探测与自适应并发下调；管理端展示冻结原因和恢复时间。自动冻结默认关闭，按需在运行设置中启用。
- 支持在管理端设置全局请求位置与时区，也可为出站代理单独配置。代理自定义值优先于全局设置，用于 OpenAI/Codex Responses 的环境日期、时区和 Web Search 位置，不改变实际出口 IP。
- 新增 Linux amd64/arm64 一键安装脚本，使用 Docker Compose 部署并生成初始配置。重复执行保留现有配置，已有实例升级仍按部署指南操作。

## 问题修复

- 修复 IPv6 出口的代理探测，识别本次连接实际使用的 IPv4 或 IPv6 地址。
- 修复二进制在线更新的前端资源目录选择，使更新与回滚使用服务实际提供的静态资源目录。
- OpenAI 额度更新时同步明确的套餐变化，避免管理端长期保留旧套餐信息。
- 手动禁用的账号仍可进行管理员连接测试，测试不会重新启用账号参与普通请求调度。
- 改善下游 SDK 和浏览器请求与 Codex 协议的兼容性，统一会话头别名，过滤不适用的请求头及顶层参数，并保留业务扩展和嵌套工具定义。

## 体验优化

- 账号与用量表格支持选择显示列、恢复默认配置，并在当前浏览器保存偏好。
- 优化添加账号时的服务商选择及额度预测提示，改善窄屏和键盘操作体验。

## 升级说明

- 从 v3.8.0 升级会自动执行 `0010_account_auto_freeze.sql` 和 `0011_proxy_request_location.sql`；v3.8.0 已发布的迁移文件保持不变。升级前请备份数据库。
- YAML 配置中的未知或已移除字段会被忽略，并在启动控制台提示。旧的 `openai.wire_profile.location` 可以保留但不再生效；如需继续覆盖请求位置，请将值填入管理端「系统设置 → 运行设置 → 请求时区与位置」后启用。旧值不会自动导入，全局位置覆盖默认关闭；缺少必填字段或已知字段不合法仍会阻止启动。
- 自行调用 `POST /api/admin/settings/update` 的客户端需同步完整请求结构，补齐请求位置和账号自动冻结相关字段；该接口仍按完整配置替换，字段约束见 API 文档。
