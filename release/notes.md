# v3.21.3

同步官方 v3.21.3，保留本 fork 的定制功能。本说明覆盖从本 fork v3.21.2 升级的更新。

## 修复与改进

- 修复 Codex 使用自定义 Provider 或关闭内容分类时，请求位置覆盖可能漏掉环境消息中的日期与时区的问题；缺少分类时仍识别完整、合法的环境上下文，HTTP 与 WebSocket 均适用（上游 [#366](https://github.com/zyycn/codex-proxy-rs/issues/366)）
- Codex Guardian 自动审批改为每账号独立并发与独立等待队列，普通请求保留原并发上限，两类请求互不占用名额；审批仍遵守账号请求间隔、等待时限与 Key 限额
- 修复 OpenAI 仅能在原连接继续的原生续接进入重放阶段时，失败请求可能先选择账号或改变会话绑定的问题；现在在选号前返回客户端重放提示，正常原生续接仍按原连接校验（上游 [#364](https://github.com/zyycn/codex-proxy-rs/issues/364)）
- 修正用量记录列表与详情的输入 Token 展示，扣除缓存读取与写入量，与 Key 用量页面保持相同口径；原始用量与计费口径保持不变

## 本 fork 功能

- 保留账号「仅限 Codex 官方客户端」、Turn State 字节观测、额度周期费用与重置进度、使用统计模型筛选和系统更新下载代理
- 总费用副标题继续显示每 1M Token 的平均费用；计费不完整时提示实际费用可能更高
- 已移除的按 Turn State 长度阻断功能保持移除

## 升级事项

- 从 v3.21.2 升级无需新增数据库迁移
- 已保存的自动审批并发配置继续生效，但大于 0 时改为额外的独立额度：普通并发为 10、审批额度为 3 时，可以同时运行 10 个普通请求与 3 个审批请求；设为 0 时仍共用普通并发
- 请求位置覆盖只修改请求中的日期、时区与位置字段，不修改客户端操作系统；模型通过 `date` 等工具读取的本机时区仍可能是真实值

更新包包含前端、Linux AMD64 二进制、配置模板与封口插件清单，按 Debian bookworm / glibc 2.36 基线构建，供管理端在线更新使用。
