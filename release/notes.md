# v3.21.4

修复 xAI 账号额度快照长期不刷新，以及未指定推理强度时使用记录为空的问题。本说明覆盖从本 fork v3.21.3 升级的更新。

## 修复与改进

- xAI 后台额度任务现在也刷新正常及额度状态尚未确认的账号，每 5 分钟向官方 billing 接口同步，避免一直显示旧周期的剩余额度
- 额度耗尽的账号仍按上游重置时间复核；没有重置时间时保留 10 分钟回查规则，失败刷新保留 5 分钟节流，停用和访问令牌已过期的账号不进入额度刷新
- xAI 新请求未指定 `reasoning.effort` 时，使用记录显示 `default`，表示由上游决定默认强度；显式指定的强度继续原样记录，此改动不会向上游请求补写或修改推理参数
- 补充正常账号刷新、失败节流、耗尽账号复核、凭据有效期和推理强度观测的回归覆盖

## 升级事项

- 从 v3.21.3 升级无需新增数据库迁移
- 历史使用记录不回填推理强度；`default` 不代表固定的 `high` 或其他具体档位
- 保留本 fork 的既有定制功能，已移除的 Turn State 长度阻断保持移除

更新包包含前端、Linux AMD64 二进制、配置模板与封口插件清单，按 Debian bookworm / glibc 2.36 基线构建，供管理端在线更新使用。
