# v3.8.0

## 新增功能

- 账号支持模型白名单与黑名单，可为不同账号分配不同模型；支持单独编辑、批量设置和 CPR 导入导出。限制按模型映射后的上游 ID 精确匹配，并复用现有调度策略、重试与安全换号逻辑。
- 新增 API Key 用量页。持有者可在登录页切换为密钥登录，查看自己的请求量、Token 与费用、趋势、请求日志、额度和健康时间线；只能访问当前密钥的数据。
- 新增 Key 与账号并发排队设置，可分别配置最大等待数量和等待超时。账号满载时先尝试其他可用账号；队列满或等待超时会返回明确错误，取消请求会释放等待位置。
- 账号支持备注，方便记录用途和管理信息；凭据刷新与重新授权保留已有备注。

## 问题修复

- 修复 Codex 使用 WebSocket 时遇到部分上游错误后长时间停留在“正在思考”的问题。将客户端无法识别的裸错误帧转换为 `response.failed`，让客户端及时结束等待并处理失败。
- 修复 API 密钥列表中长名称与标签被直接裁切的问题，超出列宽时显示省略号，悬停可查看完整内容。

## 体验优化

- 模型限制使用分段选择器和模型勾选卡片，支持搜索模型、输入 ID 后回车添加，以及统一的空状态展示。
- 批量编辑默认展开全部账号设置，只保存实际修改的字段，保留各账号未修改的并发、权重、分组和代理配置。

## 升级说明

- 从 v3.7.2 升级时，服务启动会自动执行 `0007_account_notes.sql`、`0008_concurrency_queues.sql` 和 `0009_account_model_access.sql`。升级前备份数据库；已有账号默认不限制模型，排队默认关闭，需在运行设置中按需启用。
- 浏览器认证改用 `/api/auth/*` 和 `cpr_session`，旧登录接口与 Cookie 不再接受，升级后需要重新登录。调用旧认证接口的自建前端或脚本需同步调整；`/v1/*` 的 Bearer Key 和管理接口的 `x-api-key` 鉴权保持原有用法。
- 新增可选配置 `client.session_ttl_minutes`，控制密钥登录的固定会话有效期，默认 1440 分钟。自行调用运行设置更新接口时，需增加 `maxWaitingPerKey`、`maxWaitingPerAccount` 和 `concurrencyWaitTimeoutSeconds` 三个字段。
- 账号模型限制适用于 Responses 文本请求及模型目录；Images、独立 Search 和管理员连接测试保持原有行为。白名单与黑名单不会扩大账号本身的上游模型权限。
