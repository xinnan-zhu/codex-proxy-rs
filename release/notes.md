# v3.16.0

## 新增功能

- 智能调度新增设置入口，可调整负载、剩余额度、健康、首输出延迟、额度重置和排队压力六项评分系数，并可开启高权重账号恢复后的自动回切
- 保留原有默认调度行为：额度重置与排队压力系数默认为 0，自动回切默认关闭；支持恢复默认配置，保存后对新请求生效
- 插件新增自有分组、Client Key 和自动维护能力，可在启用、重启及账号配置变化后维护已授权资源，升级时沿用已有资源

## 问题修复

- 修复停用调度的 OpenAI、xAI 账号停止自动续期的问题，凭据刷新不会重新启用账号；恢复账号重新授权时的链接生成与重新生成流程
- 模型列表按发现该模型的账号、当前 Key 的账号范围及模型策略过滤，避免展示当前范围内不可见的模型
- 改善 Codex OAuth 大请求处理：在 WebSocket 发送前为完整新请求选择 HTTP/SSE；需要完整历史恢复的增量续接返回客户端可识别的恢复信号
- 修复插件更新检查被旧缓存影响的问题，按版本识别可用更新，并简化适配平台的安装包选择与升级操作
- 修复 HTTP 部署下插件页面无法正常打开的问题，统一插件页面桥接与管理请求超时，避免耗时操作被前端提前中断

## 升级说明

- 支持从 v3.15.2 升级，启动时自动创建插件资源归属表并补充智能调度配置；升级前请备份数据库
- 使用新增插件能力时需接受对应权限；停用或删除插件配置不会自动删除其创建的分组和 Key，需要撤销访问时请在 Key 管理中处理
