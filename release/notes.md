# v3.35.0

## 按密钥、模型设置 Fast

- 创建或编辑 API 密钥时，可为每个上游模型选择继承、开启或关闭 Fast
- 密钥的显式模型设置优先于分组，未配置的模型继续继承分组设置；模型别名共用实际上游模型的规则
- 支持搜索模型，保留暂时不在目录中的已保存规则；目录未声明 Priority 能力的模型无法在界面中开启 Fast
- Fast 设置作用于 OpenAI Responses，HTTP 与每轮 WebSocket 请求使用各自冻结的策略，同次请求重试保持一致

## 额度重置后自动恢复

- 可选择在密钥范围内可用账号最早的周／月额度重置时，一次性清除单独开启的 Fast，保留显式关闭规则
- 恢复后继承分组设置，分组本身开启 Fast 时仍可能使用 Fast
- 支持识别上游提前强制重置，收到新的周／月额度观测并确认重置后提前恢复，不必等到原计划时间
- 恢复计划和确认进度跨重启保留，普通编辑不会延长计划，也不会把重置前的旧设置重新开启
- 缺少有效周／月重置时间时会提示原因，避免启用无法执行的恢复计划

## 升级说明

- 启动时自动增加密钥模型规则和恢复计划字段，现有密钥默认继承原有分组策略，自动恢复默认关闭
- 提前强制重置的识别依赖网关取得新的上游额度观测，主动使用重置卡也按随后回读的周／月额度判断
