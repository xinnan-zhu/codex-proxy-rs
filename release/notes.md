# v3.26.2

## 修复与改进

- 修复 OpenAI `turn_rate_limit_exceeded` 被扩大为账号冷却的问题，保留原始错误和 `Retry-After`，避免后续请求被本地误挡
- OpenAI 明确返回 `503 + error.code=server_error` 时按既有安全边界进行有界重试；区分重试耗尽后换号与直接返回错误的策略，尊重上游等待时间，已交付正文或工具活动后不重放
- 对带轮次标识的 Codex 请求短暂记录失败轮次，抑制客户端对同一失败轮次重复触发「耗尽后返回错误」重试，减少无效等待；不同客户端 Key 的状态隔离
- 修复流式失败与 WebSocket 复用时重复写回旧 Cookie 的问题，区分凭据版本冲突与存储故障
- 代理管理支持独立启停及账号解绑；禁用时保留账号绑定并按直连执行，账号与插件来源不再允许新选禁用代理。本 fork 的系统更新下载代理同步遵循启停状态
- 隐私规则支持在一条通用规则内按顺序配置多个规范化步骤，并改进规则编辑、预览与列表展示
- 管理端大型 JSON 响应启用 gzip，排除公开插件路由，减少列表与统计响应传输量
- 修复初次恢复登录会话失败时未显示登录页的问题；账号批量编辑默认关闭调度，保存时应用界面显示的开关值，并修复侧边栏键盘焦点显示
- Windows 离线安装包优先解析 Microsoft Store，最多等待 30 秒后按架构回退到 OpenAI 官方包，修正包大小与来源说明
- 更新 rustls 安全依赖，并改进 CI 的 Cargo 缓存归档流程

## 升级事项

- 新增官方 `0031` 与 `0032` 数据库迁移，为已有代理默认启用，并将隐私规则转换为步骤列表；保留既有规则开关、顺序与失败边界。已发布迁移保持不变，升级前备份数据库
- 自行调用隐私规则管理 API 时，规则的处理参数改放在 `steps` 数组中；非对象规则配置会阻止迁移，需先修正原始配置
- 系统更新所选代理被禁用时暂时使用直连，重新启用后自动恢复该代理；管理界面会标注禁用状态
