# v3.39.1

## 上游同步

- 合并官方 v3.39.1 及其后的账号额度布局、OAuth 结果通知修正
- 支持通过 Responses 接入 Chat Completions，完善 Codex 166 模型目录、Guardian 路由和模型能力匹配
- 加入 CPR 互联的节点发现、账号池及额度共享，支持编辑账号名称和逐字段修改插件敏感配置
- 使用统计按卡片和所选指标独立查询，新增平均／峰值请求并发趋势，减少慢查询对其他卡片的影响
- 修复 WebSocket 保活、慢上传、搜索激活前重连、会话亲和抖动及 Retry-After 等待过长等问题
- 修复配置并发提交时的快照重载和代理删除冲突后的锁释放，优化双栈代理成功出口延迟显示
- 保留已确认归属的同轮 Turn State，完善客户端追踪头透传及账号安装身份，部署路由配置继续优先
- 更新依赖并完善账号错误保护规则、账号套餐与额度展示

## 本仓库功能适配

- 保留按 Key、实际上游模型设置 Fast，显式开启／关闭优先于分组，未配置模型继承分组
- 保留可选的额度重置后自动恢复，收到新的额度观测并确认上游提前强制重置时也会触发
- 保留每 $1 可用 M Token 的费用效率，计费不完整请求不参与计算，不显示不完整计费提示
- 适配新的统计接口，缺少上游计时时继续按网关耗时估算速率，并显示估算样本数
- 保留账号 Codex 客户端限制、周期费用／重置进度、xAI 额度刷新和推理强度记录、系统更新代理
